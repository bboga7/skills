# Final checklist

Run `scripts/audit.py` first. This list covers what a script cannot judge.
Go through it with the finished page open. If an answer is "no", fix it before you hand over.

## Idea

- [ ] I can say the page's idea in one sentence, and the user would recognize their project in it.
- [ ] Color, type, layout and motion each follow from that idea.
- [ ] If I removed the logo and name, this page could still only belong to this project.

## Copy

- [ ] Every section passes the swap test (a competitor could not paste it unchanged).
- [ ] The first screen says what this is, who it is for and what to do next.
- [ ] Every number, name, quote and claim comes from the brief or the user. Nothing about prices,
      process, guarantees or what customers get was guessed.
- [ ] Missing optional details were left out. Placeholders remain only for essential details,
      none of them in the first screen.
- [ ] The page does not talk about itself (fonts, code, "no tracking", "built by hand").
- [ ] Buttons say what happens next.
- [ ] The last screen gives the reader a way to act (button, number or address), not a dead end.
- [ ] One voice from top to bottom (formal or informal, "we" or "I").
- [ ] For Turkish: no translation smell, consistent "siz" or "sen", correct spelling of "de/da" and "mi".

## Visual

- [ ] At least two parts of the common layout rhythm are changed (hero, card grid, quote, call to action).
- [ ] Neutrals are tinted, the accent is rare, and there is no default violet-blue gradient.
- [ ] Type has real scale contrast and comfortable line length.
- [ ] No texture, grid or pattern makes body text harder to read, on desktop or on a phone.
- [ ] The page looks intentional at 360 px wide and at 1440 px wide.

## Motion

- [ ] There is one signature moment, and I can say what it helps the reader notice.
- [ ] Nothing loops forever, nothing makes the reader wait.
- [ ] With reduced motion turned on, nothing moves and nothing is hidden.

## Technical

- [ ] No external requests: fonts, scripts, styles, images and icons are all local or inline.
- [ ] Keyboard only: every link and button can be reached, and the focus is visible.
- [ ] `lang` is set, there is one `h1`, headings are in order, images have `alt` text.
- [ ] The audit score is 85 or higher, and every kept finding has a reason.

## Hand-over

- [ ] I listed every placeholder the user still has to fill.
- [ ] I summarized the idea and the key decisions in a few lines, so the user can keep or change them.
